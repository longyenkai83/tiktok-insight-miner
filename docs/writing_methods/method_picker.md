# Method Picker — Chọn method nào theo loại nội dung

> **Cách dùng**: Tra bảng dưới để biết khi viết loại content nào → mở file method nào.
>
> **Quy tắc**: Pick **2-4 method** mỗi output, KHÔNG dùng hết. Chọn method match brand (qua voice profile).

---

## Bảng tra nhanh — 7 loại nội dung

| Loại content | File methods PICK | Note |
|---|---|---|
| **Reel 60s / TikTok video** | `short_video_methods.md` + `hook_methods.md` + `storytelling_methods.md` + `persuasion_methods.md` (CTA) | Format chặt, hook + story + CTA |
| **Facebook post (300-600 chữ)** | `hook_methods.md` + `storytelling_methods.md` + `persuasion_methods.md` (soft CTA) | Bài kể chuyện + insight + lời mời |
| **Caption ngắn (<100 chữ)** | `hook_methods.md` (ngắn) + 1 câu CTA từ `persuasion_methods.md` | Hook + big idea 1 câu + CTA mềm |
| **Bài kể chuyện dài (>800 chữ)** | `storytelling_methods.md` (đủ 7 thành phần) + `hook_methods.md` (mở) | Có không gian thể hiện hành trình + nhận ra |
| **Bài giáo dục / chia sẻ kiến thức** | `hook_methods.md` (counter-belief) + `persuasion_methods.md` (belief shift) + `editing_checklist.md` | Lật ngược suy nghĩ sai phổ biến + thay bằng góc nhìn mới |
| **Bài bán mềm (sale từ post)** | `storytelling_methods.md` + `persuasion_methods.md` (objection + soft CTA) | Story trước, sản phẩm xuất hiện cuối cùng như giải pháp tự nhiên |
| **Lead magnet CTA** (post xin email / DM) | `persuasion_methods.md` (comment keyword CTA + desire amplification) | CTA cụ thể, không hứa quá |

## Quy tắc chọn method

### Quy tắc 1 — Đi từ outcome, không đi từ method

❌ "Hôm nay mình sẽ thử method paradox hook" — tay cầm búa nhìn cái gì cũng thành đinh
✅ "Angle này cần khiến audience dừng lại + nghĩ ngược lại — paradox hook hợp" — outcome quyết method

### Quy tắc 2 — Match method với archetype brand

| Brand archetype | Methods phù hợp |
|---|---|
| **Caregiver** (vd chị Hiền) | Hard truth, inner question, storytelling cá nhân, soft CTA |
| **Sage** (chuyên gia) | Counter-belief, paradox, belief shift, framework |
| **Hero** (KOL build community) | Mistake/lesson, before-after awareness, story-opening |
| **Lover** (lifestyle, đẹp) | Specific pain (cảm xúc), nature metaphor, soft CTA |
| **Explorer** (lifestyle tự do) | Story-opening, paradox, in medias res |
| **Outlaw** (challenger) | Counter-belief mạnh, hard truth thẳng |

→ Brand archetype lấy từ `profiles/<brand>/voice_profile.md` mục Q hoặc `about.md` Brand archetype section.

### Quy tắc 3 — Match method với mục tiêu của bài

| Mục tiêu chính của bài | Methods ưu tiên |
|---|---|
| **Tạo cảm giác "đây là mình"** | Inner question, specific pain |
| **Lật ngược suy nghĩ sai** | Counter-belief, paradox, belief shift |
| **Build trust qua trải nghiệm** | Story-opening, mistake/lesson, before-after |
| **Đẩy người đọc làm action nhỏ** | Hard truth + soft CTA cụ thể |
| **Bán mềm sản phẩm** | Storytelling + objection handling + soft CTA |

### Quy tắc 4 — KHÔNG mix quá nhiều method 1 bài

- 1 bài → tối đa 4 method (1 hook + 1 story + 1 persuasion + 1 CTA)
- Nhiều hơn 4 → bài thành rối, mất focus
- Nếu thấy bài cần 5+ method → bài đó nên tách thành 2 bài

## Workflow chuẩn — từ angle đến draft

```
[1] Có Angle 01 (qua bank → select)
     │
     ▼
[2] Đọc profiles/<brand>/{about, voice_profile, write_rules}
     │
     ▼
[3] Quyết output type (Reel? FB post? Caption? Cả 3?)
     │
     ▼
[4] Mở method_picker.md (file này) → chọn 2-4 method file
     │
     ▼
[5] Đọc các method file đã chọn → pick concrete methods
     │
     ▼
[6] Viết draft, áp các method đã pick
     │
     ▼
[7] Chạy editing_checklist.md
     │
     ▼
[8] Anh/brand owner duyệt → xuất bản
```

→ Bước 4-5 là **TÚI ĐỒ** lấy ra dùng. Bước 7 là **kiểm tra cuối**.
